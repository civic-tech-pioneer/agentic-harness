## Goal

The kernel crate has the pieces quotas are built from, in a new
`kernel/src/quota.rs`: the kernel settings for the caps (`Limits`), the two
accounts as they are stored (`Usage` at `quota/<owner>` and `quota`), and a
metered state (`Metered<S>`) that wraps any `State` and, while a call has it
open, adds up the change in bytes of every charged key that call writes or
deletes, as 9.3 "Quota", "As built (S25)", "Bytes" defines a key's bytes and
which keys are charged. Nothing calls it yet: S25-2 puts it under the kernel.

## Acceptance

AC1. **Limits.** `Limits::default()` is `{owner_sessions: 64, owner_bytes:
64 MiB, account_bytes: 224 MiB, reserve_bytes: 32 MiB}` (MiB = 1 048 576).

AC2. **Usage.** `Usage::load(st, key)` of an absent or unreadable value is
`Usage::default()` (all zero, no pages). `save` then `load` gives the same
value. The JSON is `{"bytes":<n>,"sessions":<n>,"pages":[<n>,...]}`, `pages`
left out when empty. `Usage::owner_key("a/b%c")` is `"quota/a%2Fb%25c"` (the
owner segment of 9.1: `%` to `%25`, then `/` to `%2F`); `Usage::ACCOUNT` is
`"quota"`. `add(delta)` adds a signed delta to `bytes`, never below 0.

AC3. **Scopes.** `scope(key)` is `Scope::Record` for `session/<id>`;
`Scope::Session` for `queue/`, `entries/`, `wire/`, `loop/`, `stream/`,
`live/`; `Scope::Owner` for `key/` and `owner/`; `Scope::Kernel` for every
other key (`slots`, `slots/wait/<n>`, `active/<n>`, `quota`, `quota/<owner>`,
`profile/`, `access/`, `adopted/`, anything unknown). A prefix matches only
with its `/` (`sessionx` is `Kernel`; `slots/wait/1` is `Kernel`).

AC4. **Metering.** On a `Metered` that is not open, `put`, `get` and `delete`
pass through and charge nothing. After `open()`, each `put` of a charged key
(any scope but `Kernel`) adds `(key.len() + new.len()) - (key.len() +
old.len())` to `Change::owner`, `old` being the bytes before the put (a
missing key counts as costing 0, its name not counted either); each `delete`
of a present charged key subtracts `key.len() + old.len()`. Changes of
`Scope::Session` keys are also added to `Change::session`. `Kernel` keys are
never charged. `change()` returns the change so far without ending it;
`close()` returns it and stops metering. `open()` starts again from zero.

AC5. **Few reads.** The old size of a key is taken from the last `get` or
`put` of that key since `open()` (the meter keeps the sizes it saw); only a
key it has not seen is read through the inner state first, once. Proven with
`MemState` counts: `open`, `get("entries/s/0")`, `put` of it -> one inner
`get`; `open`, `put("queue/s")` twice -> one inner `get` (none on the second).
A `put` the inner state refuses (`TooLarge`) charges nothing.

AC6. **Uncharged and adjusted.** `delete_uncharged(key)` deletes without a
read and without a charge (for `delete`, which frees a session by its
record's `bytes`). `adjust(c)` adds a `Change` to the running change.

AC7. **The inner state.** `Metered<S>` derefs (and derefs mutably) to `S`,
so `k.state.counts()`, `k.state.reset_counts()` and `k.state.get_keys()` of
a `MemState` keep working; `into_inner()` gives `S` back; it implements
`State`. `MemState::entries()` iterates the stored `(key, value)` pairs
without counting, so a test can sum what is charged.

AC8. **Exact.** A test opens a `Metered<MemState>` on a state with some keys
of each scope, does a mix of puts (new, grown, shrunk) and deletes, and
`close().owner` equals the sum over charged keys of `key.len() + value.len()`
after, minus before (computed with `entries()`); `session` the same over
`Scope::Session` keys only.

## Interface

Provided to S25-2 (fixed; S25-2 may add, not change):

```rust
// kernel/src/quota.rs, re-exported from lib.rs
pub const OWNER_SESSIONS: u64 = 64;
pub const OWNER_BYTES: u64 = 64 << 20;
pub const ACCOUNT_BYTES: u64 = 224 << 20;
pub const RESERVE_BYTES: u64 = 32 << 20;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Limits { pub owner_sessions: u64, pub owner_bytes: u64, pub account_bytes: u64, pub reserve_bytes: u64 }
impl Default for Limits { /* AC1 */ }

#[derive(Debug, Clone, Default, PartialEq, Eq, Serialize, Deserialize)]
pub struct Usage {
    pub bytes: u64,
    pub sessions: u64,
    #[serde(default, skip_serializing_if = "Vec::is_empty")]
    pub pages: Vec<u32>,
}
impl Usage {
    pub const ACCOUNT: &'static str = "quota";
    pub fn owner_key(owner: &str) -> String;
    pub fn load(state: &mut impl State, key: &str) -> Usage;
    pub fn save(&self, state: &mut impl State, key: &str) -> Result<(), KernelError>;
    pub fn add(&mut self, delta: i64);
}

/// 9.1: `%` to `%25`, then `/` to `%2F`.
pub fn segment(owner: &str) -> String;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Scope { Record, Session, Owner, Kernel }
pub fn scope(key: &str) -> Scope;

#[derive(Debug, Default, Clone, Copy, PartialEq, Eq)]
pub struct Change { pub owner: i64, pub session: i64 }

pub struct Metered<S: State> { /* inner, open flag, sizes seen, change */ }
impl<S: State> Metered<S> {
    pub fn new(inner: S) -> Self;
    pub fn into_inner(self) -> S;
    pub fn open(&mut self);
    pub fn change(&self) -> Change;
    pub fn close(&mut self) -> Change;
    pub fn adjust(&mut self, c: Change);
    pub fn delete_uncharged(&mut self, key: &str);
}
impl<S: State> State for Metered<S> { /* AC4, AC5 */ }
impl<S: State> std::ops::Deref for Metered<S> { type Target = S; }
impl<S: State> std::ops::DerefMut for Metered<S> {}
```
