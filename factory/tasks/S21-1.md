## Goal
The kernel has the session record of TECHNICAL 9.3 and the queue `queue/<id>` as plain Rust
types over `State` (S11's `kernel/src/state.rs`): the record with its caps, the turn JSON of each
state, and the queue with its caps and its `{"type":"queue"}` push value. The error type gains
the two variants of 2.3 that the kernel lacks: `too-large(u64)` and `busy`. No calls yet (S21-3).

## Acceptance
AC1 `Turn` serializes to exactly each of the ten lines of the 9.3 block "The turn state is this
    JSON" (key order as written there) and each line parses back to an equal `Turn`;
    `expires-at` of `waiting` and `until` of `paused` are omitted when `None`; `seconds`,
    `tools`, `tokens` of `idle` are omitted when `None`. `Turn::entry_body()` is the JSON without
    `activity`. `Turn::is_active()` is true for running, waiting, paused only.
AC2 `Record` round-trips through `session/<id>` (`Record::save`, `Record::load`) with kebab-case
    keys (`claude-uuid`, `active-page`, `next-index`, `tool-errors-in-a-row`, ...).
    `Record::save` of a record whose serialization is over 512 KiB is `Err(TooLarge(524288))`
    and writes nothing.
AC3 Caps: `check_key` on 257 bytes is `TooLarge(256)` (256 passes); `check_title` the same;
    `Record::add_allow` refuses the 65th allow, an allow over 1 KiB, and one that takes the total
    past 64 KiB with `TooLarge(65536)`, leaving `allows` unchanged; `add_stream` past 10 ids and
    `add_deadline` past 64 return `Err(Busy(..))` naming the cap; `chunks` at 16 384 is
    reported by `Record::chunks_full()` (9.3 case 53: a session at 16 384 chunks is at quota).
AC4 `Record::meta()` gives S11's `transcript::Meta { chunks, last: next_index - 1 }` and
    `Record::set_meta(&Meta)` writes them back (`next-index = last + 1`).
AC5 Queue: `check_input` of an input over 262 144 bytes is `TooLarge(262144)`. `Queue::push`
    numbers inputs from 1 per session (numbers never reused, also after `remove`), refuses the
    33rd input and any push that takes the total past 2 MiB with `QueueFull`, unchanged.
    `remove(n)` of a number not in the queue is `UnknownInput(n)`. `take_oldest` gives the
    lowest number. `push_value()` is `{"type":"queue","inputs":[{"n":1,"input":"<input JSON as a
    string>"}, ...]}`. `Queue::load` of an absent key is the empty queue; `Queue::save` of a
    never-used queue (`next` 1) leaves the key absent, and of an emptied one (`next` > 1)
    stores it with its `next`, so numbers never repeat within a session (push 1, remove 1,
    save, load, push gives 2).
AC6 `KernelError::TooLarge(n).code()` is `"too-large"` and its message carries `n`;
    `KernelError::Busy(cap)` is `"busy"` and its message names the cap text.

## Spec
TECHNICAL 9.3 (record, "Sizes", cap table, turn state table and JSON), 9.1 (`session/<id>`,
`queue/<id>`), 2.3 (error variant, `too-large` carries the limit in bytes), 12.

  `STREAMS = 10`, `DEADLINES = 64`.
  `pub enum Turn { Running { since: u64, activity: Option<Activity> }, Waiting { asks: Vec<String>, expires_at: Option<u64> }, Paused { until: Option<u64> }, Idle { stop: Stop, seconds: Option<u64>, tools: Option<u64>, tokens: Option<u64> }, Unknown, ResumeLost }`,
  `pub enum Stop { Completed, Interrupted, Stopped { limit: String }, Failed { error: String } }`,
  `pub enum Activity { Checking { on: String }, Compacting, Consent { what: String } }`;
  `Turn: Serialize + Deserialize + Clone + PartialEq + Debug`, `Turn::to_json(&self) -> Value`,
  `Turn::entry_body(&self) -> Value`, `Turn::is_active(&self) -> bool`.
  `pub struct Deadline { pub what: String, pub at: u64 }`,
  `pub struct Counters { pub turns: u64, pub tool_errors_in_a_row: u64, pub tokens: u64 }`,
  `pub struct OpenAsk { pub id: String, pub kind: String /* "ask" | "check" */, pub i: u64 }`,
  `pub struct Record { pub id, owner, key, profile, backend, title: String; pub handle, workspace, claude_uuid, parent: Option<String>; pub children: Vec<String>; pub turn: Turn; pub boot: u64; pub active_page: Option<u8>; pub allows: Vec<Value>; pub counters: Counters; pub chunks: Vec<u64>; pub streams: Vec<String>; pub deadlines: Vec<Deadline>; pub open: Vec<OpenAsk>; pub next_index: u64; pub created: u64; pub updated: u64 }`

  ask entry, so a decision can repeat the ask (9.4) after the adapter's memory is gone.
  `Record::key_of(id) -> String` (`session/<id>`), `Record::load(&mut impl State, id) -> Option<Record>`,
  `Record::save(&self, &mut impl State) -> Result<(), KernelError>`,

  `Record::add_allow(&mut self, Value) -> Result<(), KernelError>`,
  `Record::add_stream(&mut self, String) -> Result<(), KernelError>`,
  `Record::add_deadline(&mut self, Deadline) -> Result<(), KernelError>`,

  `pub fn check_key(&str) -> Result<(), KernelError>`, `pub fn check_title(&str) -> Result<(), KernelError>`.
