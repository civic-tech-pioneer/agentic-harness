Slice: S138 — enforce the session owner's authority on timer firings

## Goal
An OpenAI session continues automatically when its timer carries its owner's authority. A foreign or unverified firing ends the affected work locally and records the reason.

## Acceptance
1. AC1: An owner's timer resumes a timed pause, including across restart, and runs a retry as before.
2. AC2: A pause firing with absent origin, kernel fallback after disable, or another identity sends no model request, opens or calls no toolset and requests no consent. The session shows the failure and releases its deadline.
3. AC3: Foreign retries and ask expiry do only cleanup, without sending work through the slot drain or a delegated parent.
4. AC4: The component reads Watane's existing timer import through the buffered call adapter. Harness uses its default or its timer-origin override, while a real host resolves the origin.

## Spec
VISION goals 1 and 5, FUNCTIONAL AGT-F-26 and AGT-F-28, TECHNICAL 2.1, 2.3, 9.3, 9.5, 14, 15 and case 22.

## Interface
`Host::timer_firing_origin(&mut self) -> Option<String>` reads the resolved identity in `timer-sink.fired`. `Record::owner` binds `s/<id>` to the session's authenticated caller identity. The mod imports the Watane S136 declaration without changing the callback.

## Changed tests
OpenAI loop retry and timed-resume tests, toolset and consent retries, ask expiry, the busy-slot retry, and S134 tool-free retry, counters and child resume tests explicitly fire as Alice. Existing restart-pass and Claude timers keep their assertions. The Stage D preview and load fixtures also exercise page-origin retries. Watane resolves page-origin timers to the kernel's installed identity, which cannot match the bound owner `page`. The existing automatic page-resume assertion and first toolset retry therefore conflict with the required guard. The independent slow production check in `kernel/wasm/tests/production/run.sh` uses two real host scenarios with a mod owner and a scripted endpoint. Set `WATANE_SRC` to a Watane checkout at S136 or later.
