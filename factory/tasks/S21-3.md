## Goal
A kernel maker runs `cargo test` in `kernel/` and drives sessions through the 2.3 calls on
`MemState` with a fake host: `start`, `say`, `answer`, `queued`, `unqueue`, `read`, `rename`,
`delete`, `list`, and the provider's events (turn changes, asks) as the stream item call would
give them. Turn changes keep the active index (A2, A3), the queue (9.3) and client keys
(9.1 `key/<owner>/<key>`) true, and every call does bounded work. Restart is S21-4.

## Acceptance
AC1 `start` makes a record (`session/<id>`, id from `Host::new_id`, owner = caller, backend and
    profile from `profile/<name>` in state), puts the id on the owner's page `owner/<owner>/0`,
    stores the input as a `message` entry (role `user`), sets the turn `running {since: now}`,
    writes a `turn` entry, records `HostCall::Request(Request::Turn { session, input, resume: false })`,
    adds the session to `active/` and returns its id. An absent profile, or one `check` refuses,
    is `Refused` (`{field: "profile"}` for the absent one) and writes nothing.
AC2 Keys: a second `start`, `say` or `answer` with the same caller and key returns the first
    result and changes nothing (state unchanged byte for byte, no host request); a key over 256
    bytes is `TooLarge(256)`; a call that fails (`Busy`, `QueueFull`, `TooLarge`, `Refused`, ...)
    stores no key, so the retry with the same key succeeds once the cause is gone. The same key
    of another owner is a separate key.
AC3 `say` on `idle`, `unknown`, `resume-lost` starts a turn as AC1 (returns the input's number);
    while `running` or `waiting` it queues (`Queue::push`) and returns the queue number with the
    push `{"type":"queue","inputs":[...]}`; past 32 inputs or 2 MiB `QueueFull`; an input over
    256 KiB `TooLarge(262144)` (also for `start`). `queued` lists the queue; `unqueue(n)` removes
    it and pushes the new queue; a number not queued is `UnknownInput(n)`.
AC4 Provider events (`Kernel::provider(session, ProviderEvent)`): `Out` with an `ask` entry
    with no `decision` appends it, adds `{id, kind, i}` to the record's `open`, and (kind `ask`)
    moves the turn to `waiting {asks, expires-at = earliest}`; `Out` with `idle: true` ends the
    turn `idle {completed}`; `ProviderEvent::Turn(t)` stores `t`. Each stored turn change
    appends a `turn` entry (`Turn::entry_body`) and returns the push
    `{"type":"turn","state":<turn JSON>}`. A turn that ends while inputs are queued starts the
    oldest in the same call (a user `message` entry, `running`, `Request::Turn`, the queue push).
AC5 Active index (case 67): a change that moves a session from `idle`/`unknown`/`resume-lost`
    (or new) into `running`/`waiting`/`paused` calls `active::add` and sets `active-page`; one
    that moves it out calls `active::remove` and clears it; each does 1 get and at most 1 put
    on `slots` and on one `active/` page; a change among the three active states, and a turn
    that ends and starts the next queued input, read and write no `active/` page. With 1 024
    listed (seeded with `active::add`), `start` or `say` that would add one is `Busy` naming
    1024, writes nothing and records no request; after one session leaves, the next succeeds.
AC6 `answer(caller, session, key, ask, decision)`: the decision shapes of 2.3 (the four allowed;
    any other refused with one refusal `{field: "decision"}`); an ask not in `open`, or one of
    kind `check`, is refused `{field: "ask"}`; otherwise appends the decision entry (the ask
    entry read back at its `i`, with `decision {outcome, by: "owner", for?, reason?}` added),
    drops it from `open`, records `Request::Answer { session, ask, decision }`, and moves
    `waiting` back to `running` when no ask is left. `for: session` adds the ask's `reach` with
    `Record::add_allow` (its `TooLarge(65536)` refuses the answer and the ask stays open).
AC7 Owner checks: every call on a session of another owner is `NotOwner`; an unknown id is
    `UnknownSession`. `rename` past 256 bytes is `TooLarge(256)`. `read` is S11's
    `Transcript::read` over the record's meta. `delete` removes the record, its entry chunks,
    `queue/<id>`, its active entry (if listed) and its id from the owner page, and keeps
    `key/<owner>/*`. `list(caller, after, max)` gives `SessionInfo` (2.3 `session-info`, `turn`
    as the turn JSON) of the caller's sessions only, writes nothing.
AC8 No call lists keys (`State` has no listing) and each call's gets are bounded by its inputs
    (a test counts `MemState` gets for `say` on a session with a 10 000-entry transcript: no
    more than on a fresh one, plus the transcript's last chunk).
