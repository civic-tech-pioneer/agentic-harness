## Goal

The Claude adapter fails closed on three host items S14 left open (PO decision, `factory/PLAN.md`
Deputy decisions 2026-11-21 "S14's open points"):
- an `ask-resolved` whose `by` is not exactly `expired` or `cancelled` (e.g. `user`, `allow`, a
  number, missing) is one `unknown` entry, and the ask it names **stays open**: a later
  `ask-resolved` with `by: expired|cancelled` for that id still yields its decision entry, and a
  second `ask`/`check` with that id is still `unknown` (already open);
- an `ask` or `check` whose `input` is not a JSON object (an array, a string, a number, `true`,
  `null`, missing) is `unknown`, and opens nothing;
- an `ask` or `check` whose `expires-at` is not a non-negative whole number is `unknown`, and opens
  nothing. Foreman's decision: "whole number" means a JSON integer that fits `u64`
  (`Value::as_u64()` is `Some`); `-1`, `1.5`, `5.0`, `1e3` and a value past `u64::MAX` are all
  `unknown` (the host writes the field itself as an integer, 4.5).
Everything else the adapter does today stays as it is.

## Acceptance

AC1. Ask `a1` open; `{"type":"ask-resolved","id":"a1","by":"user"}` -> one `unknown` entry whose
     `raw` is that item; then `{"type":"ask-resolved","id":"a1","by":"expired"}` -> the `ask`
     entry of `a1` with `decision {outcome: deny, by: host, reason: expired}`.
AC2. The same for `by` values `"allow"`, `""`, `1`, `null` and a missing `by`: each `unknown`,
     the ask still open afterwards (shown by a later `expired` or `cancelled` resolving it).
AC3. While `a1` is open after an unknown `by`, a second `ask` (or `check`) with id `a1` is
     `unknown` (no second card).
AC4. An `ask` and a `check` with `input` `[1]`, `"ls"`, `3`, `true`, `null` or no `input` -> each
     `unknown`, nothing opened (a following `ask-resolved {id, by: expired}` for that id is
     `unknown`). An `input` of `{}` still opens an ask.
AC5. An `ask` and a `check` with `expires-at` `-1`, `1.5`, `5.0`, `1e3`, `18446744073709551616`,
     `"5"` or `null` -> each `unknown`, nothing opened. `0` and `18446744073709551615` open one.
AC6. Each of AC1-AC5 is in a golden fixture under `kernel/tests/fixtures/adapters/claude/`
     (extend `strict.json`, or a new `strict_s19.json` with the same `row` as `strict.json`),
     read by `ac2_golden_fixtures_match`. Raw lines (`"raw"`) are fine where a `line` object
     cannot spell the value (`5.0`, `1e3`, the big number).
AC7. Every test in `kernel/tests/it/adv_s14.rs`, `adv_s11.rs`, `adversary.rs` and
     `regress_s14.rs` passes unchanged. `factory/gate.sh` passes.
