## Goal

The Bash allow grammar and the skill frontmatter rule in `kernel/src/profile.rs` equal the text
of `design/TECHNICAL.md` 4.1. `RUNNERS` holds exactly the refused first words that 4.1 lists, a
new prefix list holds the runtime prefixes 4.1 names (`python`, `pypy`, `node`, `perl`, `ruby`,
`php`, `lua`), and a test reads both lists out of TECHNICAL.md so that a word added to the spec
and missing from the code turns the test red. A `SKILL.md` frontmatter continuation line that
contains `:` is refused. `Bash(yarn ls)` stays refused.

## Acceptance

AC1. A test reads `../design/TECHNICAL.md` (path from `CARGO_MANIFEST_DIR`), finds in 4.1 the
     backticked words after "and none of these, because each runs, wraps or schedules another
     command:" up to the end of that sentence, and asserts that set equals `RUNNERS` (both ways:
     a word in the spec missing from the code fails, and so does a word in the code missing from
     the spec). It fails with the missing words named. It must find at least 100 words, so a
     broken parse cannot pass empty.
AC2. The same test reads the prefixes after "no name starting" in 4.1 (`python` ... `lua`) and
     asserts they equal the code's prefix list.
AC3. For every word `w` in the spec list: `allow: ["Bash(w)"]`, `["Bash(w foo)"]` and
     `["Bash(W:*)"]` (upper case) are refused with field `allow`. For each prefix `p`:
     `Bash(p)`, `Bash(p3.12 x)`, `Bash(pjs)` are refused (e.g. `nodejs`, `luajit`, `perl5.36.0`).
AC4. Words that are not runners stay allowed: `Bash(git status)`, `Bash(ls)`, `Bash(cargo test)`,
     `Bash(make)`, `Bash(rg foo)`, `Bash(npm test)`.
AC5. `Bash(yarn ls)` is refused; `Bash(yarn list)` is allowed (an existing test or a new one).
AC6. A skill `SKILL.md` whose frontmatter is `---\nname: a\ndescription: b\n  more: text\n---\n`
     is refused with a reason that names the `:` in a continuation line; the same with
     `  more text\n` (no colon) passes.
AC7. `cargo test`, `cargo clippy --all-targets -- -D warnings` (as `factory/gate.sh` runs it) pass.
