## Goal

The console's tests get faster before S7 adds any: `npm run test:slow` builds `ui/` once for all
its scripts (today each of 5 scripts runs its own `npm run build`: 27 s wall), the scripts share
one helper for serving `ui/` and launching Chromium, and `npm test` moves tests that need no DOM
off jsdom so its wall time drops. Behaviour of the product does not change; no assertion is
weakened.

## Acceptance

AC1. `npm run test:slow` runs `npm run build` exactly once (count the `vite build` lines in its
     output: 1), then every `console/test/*.slow.mjs` file (found by glob, so a new script joins
     without editing package.json), each against that one build. Each script's own checks are
     unchanged.
AC2. Each slow script can still run alone (`node test/<name>.slow.mjs`): it builds when it is not
     run by the runner (the runner tells it, for example by an environment variable), so a script
     run by hand never tests a stale `ui/`.
AC3. The serve-and-launch code that each slow script repeats today (the static server over `ui/`,
     the Playwright require with its NOT RUN exit 2, the browser launch) lives once in
     `console/test/slow-kit.mjs` and the scripts import it. Exit codes stay: 0 pass, 1 fail, 2 not
     run; the runner exits non-zero if any script did, and prints one line per script with its
     result and seconds.
AC4. `npm run test:slow` wall time on this machine is at most 15 s (baseline at main 1b5d324:
     27.0 s). Quote before and after, measured the same way (`date` around the command).
AC5. `npm test` (vitest) wall time is lower than the baseline 8.6 s (280 tests, 21 files),
     measured the same way, three runs each, median quoted. Ways in scope: a file whose tests need
     no DOM runs in the `node` environment (`// @vitest-environment node` or
     `environmentMatchGlobs`), the build of `test/build.test.ts` stays one build, setup that runs
     per file and is not needed is dropped. No test is deleted, skipped or merged away; the test
     count stays 280 and every assertion stays.
AC6. `factory/gate.sh` passes; `npm run typecheck` passes.

## Interface

Provides to S7-2 (and any later slow script): `console/test/slow-kit.mjs` exporting
- `async function serveUi(): Promise<{ url: string, close(): Promise<void> }>` — serves the built
  `../ui/` on 127.0.0.1, a free port;
- `async function launch(): Promise<import("playwright").Browser>` — exits 2 with the NOT RUN
  line when Playwright cannot be required;
- `function buildOnce(): void` — runs `npm run build` unless the runner already built (env
  `WA_UI_BUILT=1`).
A slow script is any `console/test/*.slow.mjs`; it calls `buildOnce()` first.
