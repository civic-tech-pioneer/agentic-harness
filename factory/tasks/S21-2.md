## Goal
The kernel has `slots` and the active index `active/<n>` (TECHNICAL 9.1, 9.3 "The active
index", A1–A3) as functions over `State`: adding a session writes one page and `slots`, removing
it writes one page and `slots`, a full index (1 024) refuses `busy` without writing, and the
restart pass can find the next entry of an older boot reading at most the four pages.

## Acceptance
AC1 `Slots::load` of an absent `slots` is all zero (`restart: None`); `save` then `load`
    round-trips; keys are kebab-case.
AC2 `add(state, &mut slots, id, boot)` puts `{id, boot}` on the first page whose count in
    `slots.active` is under 256, returns that page number, and does exactly 1 get and 2 puts
    (the page and `slots`); it reads no other page.
AC3 With 1 024 entries (`slots.active == [256; 4]`), `add` returns `Err(KernelError::Busy(m))`
    where `m` names the cap 1024, and does no put.
AC4 `remove(state, &mut slots, id, page)` drops the entry from that page only (1 get, 2 puts);
    the page's count drops by one; after it, `add` fills that room (page reuse).
AC5 A full page of 256 entries with 64-byte ids and boot `u64::MAX` is at most 24 KiB stored.
AC6 `set_boot(state, page, id, boot)` changes the entry's boot on that page only (1 get, 1 put).
AC7 `next_stale(state, &mut slots)`: reads pages from `slots.restart` (a `Some(page)`) upward,
    returns the first entry whose boot is below `slots.boot` with its page, and leaves
    `slots.restart = Some(that page)`; with none left it returns `None` and sets
    `slots.restart = None`. It reads at most the 4 pages (at most 4 gets) per call, never one
    before the cursor, and does no put (the caller saves `slots`).

## Spec
TECHNICAL 9.1 (`active/<n>`, `slots`), 9.3 "The active index" (A2, A3), "Restart" R2 (the
cursor), 2.3 and 12 (`busy` names the cap).

## Interface
Provides (fixed), in `kernel/src/active.rs`:
consts `ACTIVE_PAGES: u8 = 4`, `PAGE_SESSIONS: u32 = 256`, `ACTIVE_MAX: u32 = 1024`,
`PAGE_BYTES_MAX: usize = 24 * 1024`;
`pub struct Slots { pub provider: u32, pub request: u32, pub job: u32, pub timers: u32, pub boot: u64, pub active: [u32; 4], pub restart: Option<u8>, pub head: u64, pub tail: u64 }`
(serde kebab-case, key `slots`, `Default`), `Slots::load(&mut impl State) -> Slots`,
`Slots::save(&self, &mut impl State) -> Result<(), KernelError>`;
`pub struct PageEntry { pub id: String, pub boot: u64 }`; a page is stored at `active/<n>` as a
JSON array of `[id, boot]` pairs (compact, so 256 entries fit 24 KiB);
`pub fn page_key(n: u8) -> String`, `pub fn read_page(&mut impl State, n: u8) -> Vec<PageEntry>`,
`pub fn add(&mut impl State, &mut Slots, id: &str, boot: u64) -> Result<u8, KernelError>`,
`pub fn remove(&mut impl State, &mut Slots, id: &str, page: u8) -> Result<(), KernelError>`,
`pub fn set_boot(&mut impl State, page: u8, id: &str, boot: u64) -> Result<(), KernelError>`,
`pub fn next_stale(&mut impl State, &mut Slots) -> Option<(u8, PageEntry)>`.
`add` and `remove` save `slots` themselves (that is the second put). Takes from S21-1:
`KernelError::Busy(String)`. If S21-1 is not merged when you start, add exactly
`Busy(String)` with code `"busy"` to `kernel/src/error.rs` yourself (the foreman merges the two).
