## Goal

console's `Kernel` over `window.watane` (`call` and `on`, host 8.4 and 8.5), and `main.tsx` opens

## Interface

Takes from S32-2 (the page's `/call` names and JSON, host 6.9): `sessions.attach {session, after,
caps}` -> `{"ok":"<stream>"}` | `{"err":{"behind":n}}` | `{"err":{"backend":"..."}}`;
`sessions.read {session, after, before, max}` -> `{"ok":{"entries":[...],"last":n}}`;
`sessions.list {after, max}` -> `{"ok":[{id,title,profile,backend,turn,updated}]}`;
`sessions.say {session,key,input}`, `answer {session,key,ask,decision}`, `interrupt {session,
replacement}`, `take-back {session, allow}` as 2.3; `probe.start {key, count, every-ms}` ->
`{"ok":"<session>"}`. A case without payload is its name (`{"err":"unknown-session"}`).
`watane.call(fn, args)` resolves to the `value` (the `{"ok"|"err"}` object above) and rejects with
`WataneError {code, message}` on a host failure (treat it as a failed call). Stream messages:
`{"type":"stream","stream":id,"items":[{"seq":n,"body":"<json text>"}]}`,
`{"type":"stream-end","stream":id,"outcome":<6.9>}`.
