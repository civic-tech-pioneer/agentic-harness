## Goal

After this task Alice runs `npm run dev` in `console/`, opens the page, and sees the console's
first target on the scripted fake kernel: the sidebar with the session, the header (title,
profile, provider, workspace, any session allow, the context meter), the transcript column, and
the dock (Needs you (1), the plan "1 of 3 done", the queue, the status line, the input). A
reload shows the same transcript. `npm run build` writes `ui/` as the host serves it: one HTML
file and same-origin script and style files, no inline script, no `eval`, no outside URL, and a
hash per file. The layout values of 18.4 hold at 1280 px and under 760 px.
