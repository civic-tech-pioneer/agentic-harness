Slice: S40 — Alice runs a profile on her ChatGPT plan in the console (stage D, the consumer half)

## Goal
In the console's new-session view Alice picks one of the profiles the console may use; the view
shows which backend it runs on (Claude Code or ChatGPT), lists every refusal the kernel's `check`
returns for it, field by field, and keeps Start off while one holds. A ChatGPT session shows as such
in the header and sidebar, streams like a Claude one, shows "Paused until hh:mm" while its plan's
limit holds and goes back to running on its own when the kernel says so, and shows the context meter
from the kernel's `usage` items.

## Acceptance
AC1 The new-session view calls `profiles()` once when it opens and lists each profile as a radio row: its name, and `Claude Code` or `ChatGPT` with the model when there is one; the first is selected; with one profile (`scratch` alone) the view looks as today plus the "Runs on" line. "Runs on" shows Claude Code and ChatGPT as the frame `NewSession-2` does, the selected profile's backend marked, the other not selectable (title "Set in the profile").
AC2 On each selection the view calls `check(name, "{}")`; while the answer has refusals it shows them under a heading "Can't run on <backend>" with each `field` and `reason`, in a region with `role="status"` and `aria-live="polite"`, and Send (the first message's Start) is disabled with its reason as text; with none, Start is on. A refusal never shows a state the kernel did not report (no client-side rule).
AC3 A `start` (or `start-in-folder`) refused with `refused(list)` shows each refusal's field and reason in the error line above the composer and puts the text back (as `say`'s refusals do today); e.g. a folder typed for a ChatGPT profile shows the kernel's `folder` refusal.
AC4 A session whose `backend` is `openai` shows `ChatGPT · <profile>` in the header and sidebar meta (Claude scratch sessions keep `Scratch folder · Claude Code (unchecked)`).
AC5 With the fake kernel's ChatGPT script, the transcript shows text deltas, a tool call with its output and the turn footer; a `turn` update `paused {until}` shows "Paused until hh:mm" with the two-bars shape, and a later `running` update shows Running with no click; a `usage` item shows the context meter.
AC6 The kit's `Kernel` gains `profiles()` and `check(profile, overlay)`; `kit/watane.ts` maps them to `sessions.profiles` and `sessions.check` (as its other calls are mapped); the fake kernel answers three profiles: `scratch` (claude), `Sort` (openai, `gpt-5`, no refusal) and `Tidy` (openai, `gpt-5`, refusals `tools` and `allow`), and runs a ChatGPT script for `Sort`.
AC7 `npm test` passes; `npm run build` rewrites `ui/` (commit it); `npm run test:slow` passes.
