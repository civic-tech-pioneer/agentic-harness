## Goal

`npm run test:host` (`console/test/host/stage_b.mjs`) walks Alice's steering story on watane's own host
(`watane-dev serve` built from watane `slice/s100` until S100 merges) with dev's fake `claude`, in the
console in Chromium, and the stage B cases that need a real host and the fake: in one session she answers
an ask (Allow once, Allow `<reach>` this session, Deny… with a reason), queues a second message while
the first turn runs, presses Stop, restarts `watane-dev serve` over the same home and finds the session
where she left it (Not running: watane restarted, Continue). The checks it skipped "until S36" now run;
whatever fails on the real host is fixed in the kernel, its WASM wrapper, the provider or the console,
each fix with a test at the lowest level that shows it.

## Acceptance

Each a `check(...)` of `stage_b.mjs` (PASS on watane slice/s100, or a SKIP whose reason names the host
or stage that lacks it):
AC1. Ask, allow once (case 9, 29, 63): a fake turn with an awaited `ask` of `Read` on a file in the
     session's scratch folder; the console shows the ask card with its tool, input and the time left
     (`expires-at` equal to the host's item, read again from `read`), and "Allow `Read(<the scratch
     folder>/**)` this session" (S36-1). Allow once: the fake logs the `control_response` allow, the
     turn goes on to Idle, one decision entry `allow, by: owner` (case 73 a); a second `answer` to the
     same ask is refused (case 9) and the fake logs no second response.
AC2. Session allow and take-back (case 28): Allow … this session; the next `Read` ask in the folder is
     answered by the kernel (`allow, by: session-allow`) with no card; the fake never received an
     `updatedPermissions`; after `take-back` the same call shows a card again.
AC3. Deny with a reason: the fake logs the deny with that message, the turn ends Idle.
AC4. Queue (case 27, 45): while a `long-turn` runs, Alice sends a second message; the console lists it
     queued; `unqueue` of an input the turn already took is `unknown-input`; when the turn ends the queued
     one runs, and the fake received it exactly once (its log).
AC5. Stop (case 31, interrupt): during a `long-turn`, Stop (or Esc); the status line shows Stopping…,
     then Idle; the transcript ends with `idle {interrupted}`; an open ask during it is closed
     `cancelled` with one decision entry `deny, by: host` (case 73); the next `say` works on the same
     provider stream. Stop with a queued input ("Stop and send") interrupts with it as the replacement.
AC6. Restart (cases 68, 69, 71 on the real host): with a turn running (a `long-turn` with `every-ms`) and
     one input queued, stop the preview host (`kill -TERM` of its pid, the preview folder kept) and
     `watane-dev serve` again: `host-info.generation` is higher; the page reloads and the session reads
     "Not running: watane restarted" with Continue; its open asks have `deny, by: kernel, reason:
     restart`; the queue is kept; Continue resumes the Claude session (`--resume` in the fake's
     arguments) and the queued input runs after it; nothing doubled in the transcript.
AC7. Expiry (case 29, 73 c/e): a `check` item with no answer closes `expired` on the host's clock (a
     launch's check `timeout-s` 5, or the fake's `timeout: true`): one decision `deny, by: host, reason:
     expired`; a later `answer` to it is refused.
AC8. Cases 62, 64 on the host: a fake `raw` line `{"type":"ask",...}`, one not UTF-8 and one with a
     duplicate `type`, and a `{"type":"verdict"}` line: each an `unknown` entry, no ask, the turn not
     `waiting`.
AC9. Case 10: a `check` with `error: true` (the fake's hook_response error line) and one with `timeout:
     true` each leave the tool stopped (no allow written) and the turn goes on to idle.
AC10. Case 11 compact: a fake `raw` `system/compact_boundary` gives one `compaction` entry. (No client
     call compacts a Claude session: 2.3 has none; say so in the check's name.)
AC11. The skipped lines of S35 that this task turns into checks are gone from the SKIP list; the
     remaining SKIPs name what lacks.
