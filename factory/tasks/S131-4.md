## Interface
A test-only Rust program `console/test/host/home/` (bin `stage-c-home`) that links `watane-host`
from a watane checkout (`WATANE_SRC`): `stage-c-home --home <dir> --fake-claude <path>
--port <n> <mod folder>...` opens `Mode::Home` with a fake `Confirm` (approves installs, names the
fake `claude`, holds each consent), installs the folders, serves, prints the host's ready JSON
line; then on stdout one JSON line per question `{"event":"asked","i":n,"what":..}` and per dropped
question `{"event":"dropped","i":n}`; on stdin `{"op":"answer","i":n,"answer":"granted"|"refused"}`
and `{"op":"withdraw","local":..,"what":..}`, each answered `{"event":"done","op":..,"error":..}`.
